### 📂 Featured Systems & Architecture

* 🏥 **[Smart Hospital Management System](https://github.com/wahab-qadeer/Smart-Hospital-Management)** — Modular Java application using strict OOP patterns connected via JDBC to relational SQL databases for patient lifecycle and administrative record orchestration.
* ✈️ **[Flight Reservation System](https://github.com/wahab-qadeer/Flight-Reservation-System)** — Normalized relational schema engine handling complex SQL multi-table joins, transactional consistency, and seat allocation states.
* 🌱 **[Smart Irrigation System](https://github.com/wahab-qadeer/Smart-Irrigation-System)** — Low-latency C++ console automation engine utilizing custom moisture-evaluating matrices and sensor simulation arrays.
* 🚒 **[Smart Automatic Fire Brigade](https://github.com/wahab-qadeer/Smart-Automatic-Fire-Brigade)** — Autonomous Arduino-powered robotic vehicle incorporating Digital Logic Design (DLD) circuits, flame-detection modules, and real-time motor actuation.
* 🌤️ **[Responsive Weather Portal](https://github.com/wahab-qadeer/portfolio)** — Asynchronous frontend application built with clean semantic HTML5, CSS3 flexbox architectures, and dynamic live weather displays.
