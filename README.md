* 🏥 **[Smart Hospital Management System](https://github.com/wahab-qadeer/Smart-Hospital-Management)** — A scalable Java and OOP backend connected to relational SQL databases for high-throughput patient records and facility logistics.
* ✈️ **[Flight Reservation System](https://github.com/wahab-qadeer/Flight-Reservation-System)** — Relational database system demonstrating 3NF schema design, complex JOIN operations, and booking state machines in SQL.
* 🌱 **[Smart Irrigation System](https://github.com/wahab-qadeer/Smart-Irrigation-System)** — Low-latency C++ console automation engine using condition matrices and custom logic structures for automated water allocation.
* 🚒 **[Smart Automatic Fire Brigade](https://github.com/wahab-qadeer/Smart-Automatic-Fire-Brigade)** — Hardware-level robotics build utilizing Arduino microcontrollers, Digital Logic Design (DLD) circuits, and infrared flame-response arrays.
